Como funciona Privacidade Repositório

Seu inventário já descreve
como você pode ser atacado.

Você lista o que roda na sua infraestrutura. O MIRA cruza essa lista com CVEs conhecidos e com as técnicas do MITRE ATT&CK, e devolve duas coisas: o que precisa de correção e o que você não consegue detectar.

O AnyDesk instalado numa estação raramente aparece como vulnerabilidade. Aparece como T1219, canal de acesso remoto legítimo, usado em praticamente toda operação de ransomware recente. Scanner nenhum vai te contar isso.

Entender o método

Duas trilhas, mesmo inventário

Da versão para o CVE

Cada item do inventário vira um identificador CPE, que casa com a base de vulnerabilidades. A prioridade não sai do CVSS: sai do catálogo de exploração conhecida da CISA e da probabilidade de exploração do EPSS. Uma falha grave que ninguém explora perde para uma média que já está em uso.

Automática. Depende de haver CPE publicado para o produto.

Da função para a técnica

Software legítimo também é capacidade ofensiva. Acesso remoto, execução remota, transferência de arquivo, tunelamento. Um catálogo curado liga cada programa às técnicas ATT&CK que ele habilita, e daí ao componente de dado que você precisaria coletar para enxergar o abuso.

Curada à mão. É onde está a contribuição do projeto.

O inventário não sai do seu navegador

Uma lista de ativos, versões e programas é a descrição da sua superfície de ataque. Entregar isso a um serviço de terceiros para receber um relatório é uma troca ruim. O MIRA é um site estático: os dados de CVE e ATT&CK são baixados uma vez, o cruzamento acontece no seu computador e nada é transmitido de volta. Não há servidor para vazar.

Base ATT&CK v19.2, instantâneo de vulnerabilidades de —. Conjuntos de dados versionados no repositório para reprodução.
