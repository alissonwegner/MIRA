O que é o MITRE ATT&CK

ATT&CK (Adversarial Tactics, Techniques and Common Knowledge) é uma base de conhecimento, mantida pela MITRE Corporation, que organiza os comportamentos de ataque observados em incidentes reais. Em vez de listar vulnerabilidades, ela descreve o que um invasor faz depois que já está dentro do ambiente: como se move, como escala privilégios, como permanece sem ser detectado.

Táticas e técnicas

O framework é organizado em duas camadas. As táticas são os objetivos do invasor em cada etapa do ataque — por exemplo, obter acesso inicial ou exfiltrar dados. As técnicas são os meios usados para alcançar cada objetivo, com exemplos reais documentados por pesquisadores e equipes de resposta a incidentes.

Para que serve

Times de segurança usam o ATT&CK como linguagem comum: para mapear a cobertura de defesas, priorizar detecções, simular ataques (red team) e entender riscos a partir dos equipamentos e softwares realmente presentes na infraestrutura.

O MIRA vai cruzar o inventário cadastrado com técnicas do ATT&CK relevantes para cada equipamento. Essa análise ainda está em construção.

MIRA é um trabalho acadêmico independente. MITRE ATT&CK é marca registrada da The MITRE Corporation.
